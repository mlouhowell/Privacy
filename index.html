01 — Privacy Policy

How data is used

This policy applies to personal tools built and operated by Mary-Louise Howell for her own use. These tools access Oura ring data via the Oura API solely for personal health and training analysis.

What data is accessed

This application accesses Oura ring data belonging to the developer only — including heart rate, sleep sessions, daily summaries, workout data, stress scores, SpO2 readings, and ring configuration. No other users' data is collected.

How data is used

Data is used exclusively for personal analysis, such as visualizing training patterns and correlating cycle data with athletic performance. It is never sold, shared with third parties, or used for any commercial purpose.

Data storage

Data may be stored locally or on a personal server solely to operate the application. No data is retained beyond what is necessary. Access can be revoked at any time via Oura account settings.

Third-party services

This application connects to the Oura API, subject to Oura's Privacy Policy.
